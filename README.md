# Отчет по лабораторной работе lab02

## Выполнение работы

### Подготовка удаленного репозитория и авторизации
Был создан публичный репозиторий с названием `lab02` и добавлена стандартная лицензия MIT. 

Для обеспечения безопасного доступа к репозиторию из терминала виртуальной машины через API был сгенерирован персональный токен доступа (Personal Access Token). При генерации были выбраны права `repo` . Также были изучены предоставленные методические материалы.

### Инициализация локального репозитория
В терминале виртуальной машины была проведена подготовка локального рабочего пространства. Был создан пустой файл описания проекта `README.md`, после чего выполнена инициализация репозитория и сохранен первый базовый коммит:

* Создание пустого файла описания проекта README.md:
```bash
touch README.md
```

* Инициализация нового локального Git-репозитория в каталоге лабораторной работы:
```bash
git init
```

* Проверка текущего статуса файлов в рабочем каталоге для отслеживания изменений:
```bash
git status
```

* Добавление файла README.md в область подготовленных файлов (индекс) для последующего сохранения:
```bash
git add README.md
```

* Создание первого фиксированного коммита локально с описанием изменения:
```bash
git commit -m"first commit"
```

### Связывание репозиториев и синхронизация веток
Для синхронизации локальных файлов с сервером была настроена связь с удаленным репозиторием. Локальная ветка была переименована в `main` для соответствия структуре веток на GitHub. При первой попытке подтянуть лицензию возник конфликт независимых историй, который был успешно разрешен:

* Связывание локального репозитория с удаленным репозиторием на сервере GitHub под именем origin:
```bash
git remote add origin [https://github.com/x0mwsdc/lab02.git](https://github.com/x0mwsdc/lab02.git)
```

* Переименование текущей локальной ветки master в ветку main для полного соответствия структуре веток на сервере GitHub:
```bash
git branch -m master main
```

* Настройка стратегии слияния веток по умолчанию на классический merge (отключение режима rebase при подтягивании изменений):
```bash
git config pull.rebase false
```

* Скачивание изменений с удаленного сервера и принудительное объединение независимых историй (локального пустого README.md и файла лицензии MIT с сайта GitHub):
```bash
git pull origin main --allow-unrelated-histories
```

* Отправка локальных изменений из ветки main в удаленный репозиторий origin с установкой связи между ветками:
```bash
git push -u origin main
```

### Создание структуры проекта и исходного кода
Для правильной организации структуры C++ проекта внутри рабочего пространства были созданы необходимые каталоги, в которых затем были размещены файлы с исходным кодом и примерами использования:

* Создание структуры каталогов проекта (папок sources для исходного кода, include для заголовочных файлов и examples для примеров работы программы):
```bash
mkdir -p sources include examples
```

* Создание и наполнение исходного кода файла print.cpp (реализация функции вывода текста) в каталоге sources:
```bash
cat > sources/print.cpp
```

* Создание и наполнение заголовочного файла print.hpp (объявление функций вывода) в каталоге include:
```bash
cat > include/print.hpp
```

* Создание файла примера использования функции вывода в стандартный поток (example1.cpp) в каталоге examples:
```bash
cat > examples/example1.cpp
```

* Создание файла примера использования функции вывода в файл (example2.cpp) в каталоге examples:
```bash
cat > examples/example2.cpp
```

### Фиксация изменений и отправка результатов
После успешного создания всех файлов структуры проекта текущие изменения были зафиксированы в локальном репозитории и отправлены на удаленный сервер GitHub:

* Добавление всех созданных папок, файлов и исходных кодов структуры проекта в индекс Git:
```bash
git add .
```

* Создание коммита, фиксирующего добавление исходных файлов и примеров структуры проекта:
```bash
git commit -m"added sources"
```

* Финальная отправка всех созданных исходных кодов программы на удаленный сервер GitHub в ветку main:
```bash
git push -u origin main
```
